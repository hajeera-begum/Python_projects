## Week 2 Homework Questions

1. **Conditional Statements (if-else):** Write a program that takes an integer as input and prints whether it's positive or negative.
2. **Conditional Statements (if-elif-else):** Write a program that takes a numerical score as input and prints the corresponding letter grade (A, B, C, D, or F) based on a standard grading scale (e.g., 90+ is A, 80-89 is B, etc.).
3. **Nested If Statements:** Write a program that takes two numbers as input and checks if the first number is positive and if the second number is even.
4. **Nested If Statements:** Write a program that takes a year as input and determines if it's a leap year. A leap year is divisible by 4, but not by 100 unless it's also divisible by 400.
5. **While Loop:** Write a program that prints numbers from 1 to 10 using a `while` loop.
6. **While Loop:** Write a program that calculates the sum of all numbers from 1 to 100 using a `while` loop.
7. **Infinite Loop (and how to stop it):** Explain what an infinite loop is and how you would typically stop one in a Python script.
8. **For Loop (with range):** Write a program that prints the multiplication table of a number (e.g., 5) from 1 to 10 using a `for` loop and the `range()` function.
9. **For Loop (with list):** Given a list of fruits `["apple", "banana", "cherry"]`, iterate through the list and print each fruit.
10. **For Loop (with string):** Iterate through the characters of your name and print each character on a new line.
11. **Looping through data for calculations:** Given a list of temperatures in Celsius `[0, 10, 20, 30, 40]`, create a new list containing the temperatures converted to Fahrenheit (F = C * 9/5 + 32) using a loop.
12. **Automating Tasks with Loops:** Imagine you have a list of email addresses. Write a program that simulates sending a personalized email to each address using a loop and f-strings.
