## Homework Questions Week1

1.  **Variables and Data Types:** Define a variable `price` and assign it a floating-point value. Define another variable `quantity` and assign it an integer value. Calculate the `total_cost` and print it using an f-string.
2.  **Type Conversion:** Take the `total_cost` from the previous question (which is a float) and convert it to an integer. Print the integer value and its type.
3.  **Arithmetic Operators:** Calculate the remainder when 100 is divided by 7 using the modulus operator (`%`).
4.  **Arithmetic Operators:** Calculate 5 raised to the power of 3 using the exponentiation operator (`**`).
5.  **Comparison Operators:** Write an expression that checks if a variable `temperature` is greater than or equal to 30 degrees Celsius.
6.  **Comparison Operators:** Write an expression that checks if two strings `password` and `confirm_password` are not equal.
7.  **Logical Operators:** A student passes an exam if their `score` is greater than or equal to 70 AND their `attendance` is greater than or equal to 80%. Write an expression using logical operators to check if a student passes.
8.  **Logical Operators:** A store offers a discount if a customer is a `member` OR their `purchase_amount` is greater than 100. Write an expression using logical operators to check for discount eligibility.
9.  **Logical Operators:** Write an expression that negates the result of checking if a `number` is less than 0.
10. **Assignment Operators:** Initialize a variable `counter` to 0. Use the `+=` operator to increment it by 5. Then use the `-=` operator to decrement it by 2. Print the final value of `counter`.
11. **Assignment Operators:** Initialize a variable `product` to 10. Use the `*=` operator to multiply it by 3. Then use the `/=` operator to divide it by 2. Print the final value of `product`.
12. **Membership Operator:** Check if the letter 'e' is present in the string "programming".
13. **Membership Operator:** Check if the number 25 is NOT present in a list of numbers `[10, 20, 30, 40]`.
14. **Identity Operators:** Create two variables `list1 = [1, 2, 3]` and `list2 = [1, 2, 3]`. Use the `is` operator to check if they are the same object in memory. Explain the result.
15. **Identity Operators:** Create a variable `x = 10` and another variable `y = x`. Use the `is` operator to check if `x` and `y` refer to the same object. Explain the result.
16. **Combined Operators and F-strings:** Calculate the area of a rectangle with `length = 15` and `width = 8`. Store the result in a variable `area`. Print the result using an f-string in the format "The area of the rectangle is [area]".
17. **Conditional Logic with Operators:** Write a program that takes a person's `age` as input. If the age is 16 or 17, print "You can drive with a provisional license." If the age is 18 or older, print "You can drive with a full license." Otherwise, print "You are not old enough to drive."
18. **Employee Performance System (Extension):** Modify the employee performance check to also consider if an employee has a specific `certification` (boolean variable). An employee is now eligible for promotion if they meet the previous criteria AND have the certification.
19. **Online Course Access (Extension):** Modify the online course access check. A student can now access a course if it's in their `enrolled_courses` list OR if they have purchased a `premium_subscription` (boolean variable).
