# 🐍 Reeborg's World - Python Challenges

Welcome to my solutions for the **Reeborg's World** Python programming challenges! 🚀  
This repo contains my implementations for the popular "Hurdles" challenges (Hurdle 2 to Hurdle 4) and more as I progress.

## 📚 About Reeborg's World

[Reeborg's World](https://reeborg.ca/reeborg.html) is an educational platform that helps beginners learn programming with fun robot challenges.  
You control **Reeborg**, the robot, by writing Python code to solve various mazes and obstacle courses.
